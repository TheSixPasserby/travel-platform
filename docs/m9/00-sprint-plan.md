## 三、共享架构——不要超前重构

```
travel-platform/
├── backend/             # 原 Spring Boot + MySQL，四端共享
├── frontend/            # 原 Vue 3 Web，保留并升级主题/响应式/动效
├── mobile/              # 新增 Vue 3 uni-app：小程序、Android、iOS
│   ├── pages/
│   ├── components/
│   ├── platform/
│   ├── services/
│   ├── pages.json
│   └── manifest.json
└── packages/shared/     # 只抽取确有复用价值的纯 TS 类型/规则/Token
```

优先共享后端 API、DTO/VO 类型、纯业务校验、错误映射、设计 Token。允许 Web 和 uni-app 有不同组件。小程序不能直接用浏览器 DOM、localStorage、Vue Router、DOMPurify 和所有 Web Markdown 编辑器；在 `mobile/platform/` 封装 `uni.request`、`uni.uploadFile`、`uni.getStorageSync`、导航和图片预览。保持后端现有 `satoken` 认证语义。API 地址在不同目标中配置正确，处理微信小程序 HTTPS 合法域名、图片域名和 Android 网络访问。禁止在客户端放 AI Key、数据库密码或演示凭据。
