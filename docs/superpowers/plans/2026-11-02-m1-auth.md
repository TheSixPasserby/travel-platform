## Review Focus

1. 并发/逻辑删除账号重复注册仍由数据库唯一键拒绝，不把 SQL 细节返回客户端。
2. 密码 Unicode 码点与 UTF-8 72 字节边界正确；响应永不含哈希。
3. 已禁用用户旧 token 失效；退出和浏览器刷新状态一致，网络故障不误清除有效会话。
4. PATCH 未提供字段保持，显式 null 清空可空字段；role/userId/存在标记不能注入。
5. 真实测试库与夹具清理受限，受管图片路径/重定向不能越界。
