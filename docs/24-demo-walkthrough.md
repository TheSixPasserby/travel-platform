# 10分钟毕业演示脚本

配合[使用手册](23-user-manual.md)与[部署说明](22-deployment-and-operations.md)。以下为功能演示，不是实时旅行建议或价格承诺。

## 准备与账号

本机持久演示记录在忽略的`.local/demo/metadata.json`；随机密码只在`.local/demo/credentials.json`（600），不在文档、源代码或交付包中。三个角色：admin（山水间管理员）、author（林间旅人）、reader（沿途拾光）。由本人在本机查看凭据并登录，不录屏密码、不把凭据复制到论文或共享材料。

当前本机数据为两篇公开攻略、一篇草稿、一份两天三项目行程，读者已对成都攻略点赞收藏并留言。数据是有意保留的演示集，区别于已清理的里程碑临时验收夹具。ID以本地metadata为准；换机不会携带这些账号，按下述步骤重新准备，不覆盖同名未知账号。

换机准备：完成新专用库初始化→注册三个本人账号并自行生成不同随机密码→依[部署说明第6节](22-deployment-and-operations.md#6-管理员首次配置)精确核对ID/用户名后提升自有管理员→作者发布成都、杭州示例攻略并留大理草稿→读者互动留言→作者创建行程。仅由运营者保存密码，不设置全平台统一初始密码。

本机日常演示用开发入口`http://127.0.0.1:5173`；验证生产构建时按部署说明运行8081/5174再访问5174。重启后内存token失效，重新登录即可。主代理已用三个隔离浏览器走通生产构建流程，演示结束均退出。

## 讲解顺序

| 时间 | 身份与操作 | 展示要点 |
|---|---|---|
| 0:00–1:00 | 游客：首页→攻略列表→搜索“成都”→详情；切到目的地 | 前后端分离，公开读取、筛选分页、Markdown及图片占位 |
| 1:00–2:00 | author登录→个人中心→我的攻略，切换已发布/草稿 | 草稿私有；说明角色和资源所有权不同 |
| 2:00–3:00 | 打开大理草稿，修改一行后保存；展示上传入口和预览 | 表单校验、失败可重试、安全Markdown；别为演示上传未授权照片 |
| 3:00–4:00 | reader隔离窗口打开成都攻略，取消/再点赞收藏，查看评论 | 数据库联合唯一约束、幂等操作与真实计数；我的收藏只含公开攻略 |
| 4:00–6:00 | author→我的行程→成都两日慢行；上移项目并刷新，再恢复原顺序 | 私人时间线、手动排序持久化；日期范围与按天安排 |
| 6:00–7:00 | reader访问相同行程地址 | 页面显示拒绝访问，不出现作者行程标题/项目/编辑器；后端所有权独立校验 |
| 7:00–8:30 | admin→后台概览→攻略治理，隐藏成都攻略；reader刷新后不可见；admin恢复 | 作者不能自行解除隐藏；恢复保留首次时间、点赞收藏；治理不改正文 |
| 8:30–9:15 | admin→评论治理，说明隐藏/恢复；用户管理展示本人按钮禁用 | 普通用户无后台入口且API403；临时禁用原会话401，恢复可登录 |
| 9:15–10:00 | 展示测试证据、分层代码、限制与下一步；三窗口退出 | 已实现P0/P1，AI未接入；不把本机演练说成公网上线 |

演示可选禁用reader：先确认选中本人持有的演示账号，禁用后reader访问个人中心触发401；admin随即恢复，再用原密码登录。切勿禁用未知账号；当前管理员本人操作始终不可用。若时间不足只解释已执行的[M6证据](21-m6-test-report.md)，不临时冒险操作。

## 可复制的原创示例

标题：成都两日慢行：茶馆与街巷；目的地成都；主题城市漫游；天数2；预算示例560.00（不代表现价）。正文：

```markdown
# 成都两日慢行

这是一份毕业演示用的原创示例，不代表实时营业或价格信息。

## 第一天 · 城市散步
- 清晨在公园走走。
- 午后留一段喝茶和记录的时间。

## 第二天 · 巷子里的日常
按自己的节奏安排街巷散步，给返程留足时间。

> 出发前自行核实开放时间与天气。
```

行程示例：2026-11-14至15，第一天“茶香与街巷”，09:00公园散步、14:00街巷午后；第二天“城市的另一面”，10:00城市小展馆。地点/地址/日期仅作数据演示，非预订或导航。可留空时间，不要求调用地图或AI。

## 收尾与故障处理

结束前恢复被隐藏内容和被停用的演示账号，恢复项目原顺序；保留三角色演示集并退出登录，不批量删除数据。保存失败时留在原页读取错误，网络故障恢复服务后重试；不知道状态时先刷新/查询，不连续点击写操作。

演示失败应记录实际步骤与响应，引用现有已执行测试而不编造成功。数据库服务与开发服务保持原样；只停止演练自己记录且核实归属的进程。截图不得包含凭据、私人未知用户或调试SQL。
