# UI/UX 视觉与交互规范

## 产品气质
现代、轻松、真实旅行感、内容优先、摄影叙事。用户端应帮助游客发现目的地、阅读攻略和创建行程，而非呈现传统后台模板。

## 视觉方向
- 暖白/浅米色背景；
- 深灰或近黑文字；
- 自然绿或蓝绿色品牌色；
- 少量暖橙强调；
- 卡片圆角 12–20px；
- 桌面内容容器约 1200–1440px；
- 图片常用 16:9、4:3；
- Lucide 风格图标；
- 轻量动效并尊重减少动态效果偏好。

颜色通过 CSS variables 或 Tailwind tokens 统一管理。

## 页面重点
### 首页
大幅目的地视觉、搜索入口、热门目的地、精选/最新攻略、主题分类。不要堆叠无意义统计数字。

### 攻略广场
卡片展示封面、标题、目的地、作者和互动数据；支持关键词、目的地、标签、排序和分页。

### 攻略详情
突出标题、封面、作者、目的地、旅行信息和正文；阅读宽度适中；互动入口易发现；Markdown 安全渲染。

### 目的地详情
大图、简介、地区、推荐季节和关联攻略。标签属于攻略，不增加目的地标签关系。

### 行程规划
按天分组，以时间线或可排序卡片呈现；清楚区分日期、地点、时间和备注；移动端不依赖横向大表格。

### 管理后台
独立布局，清晰侧栏和顶部区域；表格适合管理数据；破坏性操作需确认。

## 响应式
桌面 ≥1200px；平板 768–1199px；手机 <768px。不要只缩小桌面布局，窄屏应重排导航、筛选和行程编辑。

## 图片与可访问性
使用自制、授权或明确可合法使用的素材；设置比例和 alt；处理加载失败。表单有 label、键盘可操作、焦点清晰、颜色不作为唯一状态提示。
