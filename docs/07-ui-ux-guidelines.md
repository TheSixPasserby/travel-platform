# 界面与交互约定

当前样式来自 `frontend/src/styles`、主题工具及公共组件。用户端以旅行图文阅读和地点规划为主，后台采用列表与表单组织管理操作。

## 颜色、排版与布局

使用统一的表面、文字、边框、间距和动效变量。明暗模式与主题色分别保存，内置六组色调并支持合法 HEX 自定义色。减少动态效果偏好会关闭相应过渡。

发现页与作者作品采用多列瀑布流，卡片保留原图比例并使用受控缩略图。阅读页限制正文宽度，桌面互动靠近内容，手机浏览器调整导航和互动栏。加载后的追加内容避免重置已读位置。

## 常用交互

| 场景 | 约定 |
|---|---|
| 列表 | 服务端分页或游标加载，明确初始、追加、空结果和重试状态 |
| 编辑 | 真实字段标签、上传状态、失败输入保留和提交中防重复 |
| 评论 | 两级展示，选择真实提及账号，错误与频控反馈明确 |
| 通知 | 展示收件人事件、已读状态，目标失效时反馈原因 |
| 行程 | 按日期与项目组织，确认后写入，显示新增与跳过结果 |
| 图片 | 加载和失败占位、键盘与触摸操作、原图下载 |
| 账号切换 | 清理旧状态，忽略旧账号请求的迟到响应 |

## 图片与可访问性

图片采用自制、授权或明确可用的来源，公开资料保留来源及许可。图片具有替代文本，表单有标签，状态反馈结合文字，键盘焦点可见。灯箱恢复触发焦点和背景滚动，窄屏控制保持可点击。
