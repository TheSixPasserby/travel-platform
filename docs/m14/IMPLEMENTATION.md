## 状态与安全决策

- 保留 `PreviewImage[]` 与实际点击索引；增加可选视口坐标 `sourceRect`，从按钮内的真实图片或正文图片读取。无有效矩形时回退动画。白名单筛选后按原始位置映射，重复 URL 或重复对象均保留位置。
- 缩放以图片自然尺寸为基准；适应比例取旋转后图片包围盒与可用画布的比例。缩放、旋转、位移由同一模型计算，工具栏显示实际比例，浏览图片时重置状态。
- 只在灯箱画布内接管指针/滚轮。拖动、双指与横滑需互斥，拖动阈值后不能再触发点击放大；切图、取消和卸载清理手势。
- 下载只接受现有 `/uploads/YYYY/MM/<32位小写十六进制>.<jpg|png|webp>`，同源凭据、禁止重定向、校验响应地址与类型。原始字节通过 Blob 下载；文件名由受管文件名生成，不使用图片说明或响应头。
- DOMPurify、Markdown 白名单、上传权限、数据库、M13 社区布局和归档移动端保持原实现。路由变化会关闭灯箱，作用域销毁释放预览引用。
