## 主代理复核与修正

- DSH日期策略原6测试通过后，Codex补充长补零带加号年份和直接LocalDate参数范围测试，实际RED后补固定四位格式与两端年份校验。
- READ_COMMITTED仍可能复用MyBatis首次子ID定位缓存。真实“持根锁并未提交删日/删项目→另一请求等待→提交”测试复现409代替404；根FOR UPDATE显式flushCache=true/useCache=false后，两分支及完整150回归通过。机制核对[MyBatis官方文档](https://mybatis.org/mybatis-3/sqlmap-xml.html)，未改全局缓存或数据库结构。
- 前端独立审查发现局部删除确认可被顶部整份行程操作替换，先新增行为RED，再锁定确认目标与所有相关入口。非法状态URL重试误用旧筛选同样先RED后修正；401捕获原回跳地址并避免重复捕获登录页。
- 手机初版虽无横向溢出，正文被并排按钮挤窄。人工截图发现后改为窄屏按钮置于文字下，最终实测正文宽度至少220px、无横向溢出并再次人工查看，未把“无溢出”当作完整可读性验收。
