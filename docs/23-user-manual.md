# 山水间使用手册

## 访问与账号

访客可以浏览攻略、目的地、作者主页和搜索结果。发布、互动、通知、收藏管理及私人行程需要登录。

在 `/register` 注册账号，再到 `/login` 登录。用户名为 3–50 位字母、数字或下划线，密码至少 8 个 Unicode 字符且 UTF-8 编码最多 72 字节。右上角账户入口提供主页、资料、收藏、行程、通知和退出。

`/me` 打开本人公开主页，修改资料在 `/me/settings`。昵称最多 50 字、简介最多 300 字。头像上传或移除后点击保存，支持 JPG、PNG、WebP，单图不超过 5 MiB。

## 查找攻略和地点

首页和攻略页按卡片浏览，支持城市、主题、排序和持续加载。顶部搜索可以查询攻略、城市、景点、作者与话题，切换类型后查看对应结果。搜索历史保存在当前浏览器，可清空。

目的地页展示城市和景点。城市详情包含下属景点与相关攻略，景点详情展示地址、开放票务、游玩时长和来源。动态资料不足时以页面提示为准。

作者主页展示公开作品和“手记中的目的地”。该地点列表来自作品关联关系，个人收藏与私人行程分别管理。

## 阅读与图片

打开攻略后可查看图文、作者、关联景点及互动。点击封面、正文图或图库进入原图查看器，支持切图、缩放、平移、旋转、适应与原图下载，Esc 关闭。手机浏览器可使用触摸操作。

分享按钮复制公开分享链接，对应页面包含攻略元数据。文章撤回、隐藏或删除后公开入口失效，已有收藏关系在恢复公开后继续显示。

## 点赞、收藏、评论与通知

点赞和收藏再次点击可取消。收藏列表在 `/me/favorites`，只显示当前公开的攻略。

在评论抽屉输入纯文本，最多 2000 字。可回复根评论或具体回复，列表保持两级。点击“@ 提及旅伴”搜索用户名或昵称，选择账号后保留正文中对应标记。每条最多五位，单纯手输 @ 文本不会自动建立通知关系。

本人可以删除自己的评论，管理员通过隐藏或恢复治理评论。每分钟最多发表 10 条、滚动 24 小时最多 100 条，超限按提示稍后重试。

通知入口显示未读数量。`/me/notifications` 支持全部或未读筛选、单条查看和全部已读。点击通知先记录已读，再打开攻略中的对应评论和回复页。目标失效时提示原因。

## 写攻略

1. 从“发布笔记”或 `/guides/new` 进入编辑页。
2. 填写标题、正文，按需选择主城市、真实关联景点、主题、封面、旅行天数和预算。
3. 默认使用所见即所得编辑，可切换即时渲染或 Markdown 源码。图片上传后插入正文及图库，可调整展示顺序。
4. 保存草稿后仅本人可见，保存并发布后进入公开阅读页。
5. 编辑已发布作品会保留首次发布时间，撤回为草稿后从公开列表退出。

“我的攻略”可切换草稿、已发布和已隐藏状态。隐藏作品由管理员恢复后才能继续编辑或发布，作者仍可查看和删除本人作品。保存失败时保留当前输入，离开未保存页面前先确认内容已保存。

## 手动规划与攻略地点导入

在 `/me/itineraries` 新建行程，填写名称与日期范围，再添加每日安排、地点、时间、地址及备注。每天最多 100 项，整份最多 500 项，日期范围最多 366 天。上移或下移调整同日顺序。

攻略详情及收藏的“加入行程”先列出真实关联景点。选择地点后，可加入本人已有行程的一天，也可新建行程再加入。确认结果显示新增及跳过项目，已有同一地点会按规则去重。

私人行程只有本人可访问。缩短日期若会排除现有日程，需先处理对应安排。删除行程、某天或项目先确认，归档用于个人整理，归档后仍可编辑。

## AI 行程预览

登录后进入 `/itineraries/ai`。从攻略进入时会带入来源和已选地点，可继续修改城市、日期、人数、预算、节奏、兴趣和必去条件。

生成结果先作为预览展示。可以编辑标题、每日项目和备注，或重新生成某一天。预览不会自动创建行程，点击保存并再次确认后才写入。刷新有可恢复草稿时，可选择恢复或使用当前需求。

服务关闭、超时或结果不合规时，页面保留手动创建与添加入口。生成内容需由使用者核对开放、交通、费用及当天安排。管理员负责服务配置，普通用户不填写全站密钥。

## 管理后台

管理员从 `/admin` 进入用户、攻略、评论、目的地及 AI 设置。治理操作按页面确认后执行。

- 用户管理可禁用和恢复账号，当前管理员和最后一名可用管理员受保护。
- 攻略及评论治理控制公开状态，作者正文与私人行程由各自所有者维护。
- 目的地管理维护层级、图库、地址、开放票务和来源，停用保留历史引用。
- AI 设置保存供应商、模型、端点和密钥，响应只显示是否已配置。

## 常见问题

| 现象 | 处理 |
|---|---|
| 登录状态失效 | 先保留当前未提交文字，再重新登录 |
| 图片上传失败 | 检查格式和 5 MiB 大小限制后重试 |
| 找不到本人作品 | 在“我的攻略”查看草稿或已隐藏筛选 |
| 收藏内容暂时消失 | 源攻略可能撤回或隐藏，恢复公开后关系继续生效 |
| 评论频率超限 | 按页面提示等待，删除旧评论不会清除窗口计数 |
| AI 无法生成 | 继续手动规划，由管理员检查服务配置 |
| 通知无法跳转 | 对应评论或攻略可能已失效 |

页面请求失败时使用当前重试入口。换账号后按新账号重新读取私人资料。
