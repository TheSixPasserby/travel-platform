# 山水间 · 使用手册

面向普通旅人和管理员的中文操作说明，只讲页面怎么用，不涉及实现。接口细节见[接口契约](06-api-contract.md)，后台范围见[M6 验收记录](21-m6-test-report.md)。

## 1. 访问与页面一览

未登录可浏览首页、攻略与目的地列表和攻略详情；点赞、收藏、评论、写攻略、私人行程和后台需登录。常用地址：注册 `/register`、登录 `/login`、我的资料 `/me`、攻略 `/guides`、写攻略 `/guides/new`、我的攻略 `/me/guides`、我的收藏 `/me/favorites`、目的地 `/destinations`、我的行程 `/me/itineraries`、单份行程 `/itineraries/:id`、后台 `/admin`、`/admin/users`、`/admin/guides`、`/admin/comments`、`/admin/destinations`。详情页从列表卡片点开；地址不存在时显示"页面未找到"，点"回到首页"即可。

## 2. 注册、登录与退出

1. 打开登录页，点注册入口，填写账号与密码；昵称可留空，默认使用账号。
2. 账号由字母、数字或下划线组成，长度 3–50 位；密码至少 8 个字符、UTF-8不超过72字节，不能全是空白。
3. 注册成功后回到登录页，用新账号登录一次。

登录失败只给统一提示，不说明错在哪一项，确认后可重试；密码框右侧可临时显示明文。登录过期时页面提示重新登录。退出入口在右上角；遇到网络异常会提示"退出登录没有完成"，此时并未退出，可重试。

## 3. 个人资料与头像

在 `/me` 修改昵称、简介和头像：昵称必填，最多 50 个字符；简介最多 300 字，可清空；头像支持 JPG/PNG/WebP，单张不超过 5MB。上传或移除头像后必须点"保存修改"才生效。上传失败会提示原因（格式或大小不符），换一张再试即可。

## 4. 浏览目的地与攻略

**目的地**：`/destinations` 支持按城市或景点名称搜索、按类型筛选、清空筛选和翻页。公开列表只显示可用的目的地；停用后不再出现在列表和新建选择中，但攻略或行程里已关联的历史目的地仍可通过原链接打开，并标注"历史目的地"。

**攻略列表**：`/guides` 支持搜索标题或摘要、按目的地与旅行主题筛选、按"最新发布"或"最多点赞"排序，显示总数并分页。无结果时提示换个关键词或写第一篇攻略；加载失败可"重新加载"。

**攻略详情**：正文按 Markdown 安全渲染，只呈现文字与排版，不执行其中嵌入的网页标签。图片失败时显示"图片暂时无法显示"，正文仍可阅读，刷新可重试。

## 5. 点赞、收藏与评论

- 点赞与收藏都要登录，按钮在"点赞/已赞""收藏/已收藏"间切换，再点一次即取消，重复点击不会产生多条记录。
- 收藏集中在 `/me/favorites`，可按标题或摘要搜索并翻页。列表只显示当前公开的攻略：作者撤回或被管理员隐藏后暂时看不到，恢复公开后原收藏自动重现，无需重新收藏。
- 评论需登录，内容为纯文本，保留换行，最多 2000 字；发表后详情页评论数同步更新。
- 每条评论只有作者本人能删除，删除后不可恢复；管理员不能代替作者删除评论。
- 未登录时互动区提示"登录后即可点赞和收藏""登录后评论"，并提供登录入口。

互动失败保留已知状态并可重试，不假装成功。评论发送时若登录失效，文字在当前页面输入框保留；先复制再登录，离开或更换账号后不保证保留。

## 6. 写攻略：草稿、发布与撤回

从 `/guides/new` 或"写篇攻略"进入编辑页。

1. 填写标题（必填，最多 180 字）与正文（最多 100000 字），可选填摘要、旅行天数（1–365）、人均预算（非负金额，最多两位小数）、季节、目的地和旅行主题（最多 10 个）。预算只写数字，例如 1280.00。
2. 点"保存草稿"：仅自己可见，不进入公开列表；新攻略首次保存后停在编辑页并提示"草稿已保存"。
3. 点"保存并发布"：检查标题与正文后打开该攻略公开详情，并出现在 `/guides` 列表；首次发布时间确定后不再改变。
4. 已发布的攻略仍可"保存修改"；点"撤回为草稿"才从公开列表消失。撤回后点赞收藏保留，再次发布时重新显示。
5. 点"删除攻略"需二次确认，确认后无法从页面恢复；删除后的公开入口提示内容不存在。

图片：封面与正文图片均支持 JPG/PNG/WebP、单张不超过 5MB，失败时按提示重试，上传失败不会写入攻略。正文图片会插入正文并同步到图库，最多 20 张，可在图库"前移/后移"调整展示顺序或"移出图库"。上传中或保存中切换页面会被拦下并提示稍后。

所有权：只有作者看到"编辑这篇攻略"，也只有作者能发布、撤回和删除自己的攻略。攻略被管理员隐藏后，作者在"我的攻略"里仍可见（状态为"已隐藏"），可查看和删除，但不能编辑、发布或撤回，页面会说明原因；需要恢复公开时由管理员操作。

## 7. 私人行程规划

私人行程只有本人可见，其他账号打开同一地址会被拒绝。

1. 在 `/me/itineraries` 点"新建行程"，填写名称、起止日期，可选目的地、备注和状态（进行中或已归档）。
2. 打开行程点"添加每日安排"：选择行程范围内的日期（同一天只能有一条），可填当天标题与备注。
3. 在每天下添加项目：地点名称必填，可填地址、起止时间和备注，结束时间不能早于开始时间；每天最多100项、整份行程最多500项，日期范围最多366天。
4. 用"↑ 上移""↓ 下移"调整当天项目顺序，保存后立即生效，刷新后顺序不变。
5. 缩短行程日期时若会排除已有安排，系统会拒绝并保持原数据不变；先删除多余日程再改日期。
6. 列表可按名称搜索、按状态筛选；归档只是本人整理用的状态，归档后仍可编辑。

删除行程、某天或单个项目都会先弹确认框：删除日程连带删除当天全部项目，删除项目后其余项目按原相对顺序补位，删除行程后无法从页面恢复。保存失败可重试，保存期间按钮暂时禁用。

## 8. 管理员后台

仅管理员在右上角看到"管理后台"入口。`/admin` 是概览，展示用户、攻略、目的地、评论四项数字，点"前往管理"进入对应页面；数字包含停用账号、草稿和隐藏内容，不代表公开数量，加载失败可"重新加载"。

**用户管理**：可按昵称或用户名搜索，按角色和状态筛选。对某账号点"禁用账号"或"恢复正常"都会先弹窗确认。

- 禁用是临时措施：该账号无法登录，已登录的会话访问受保护页面时会被要求重新登录；已发布攻略、评论等公开内容保持原样。
- 点"恢复正常"后该账号可重新登录，无需重新注册；保留且未过期的原token也可恢复有效，页面曾收到401则已清本地登录态。
- 你自己的那行显示"当前账号"且按钮不可用，管理员不能禁用自己；系统也不允许把可用管理员全部禁用。

**攻略治理**：可按标题或摘要搜索，按草稿、已发布、已隐藏筛选。可对已发布攻略"隐藏"、对已隐藏攻略"恢复显示"，均需确认。隐藏后公开详情与评论入口不可访问，点赞收藏关系保留，恢复后按原首次发布时间重新公开。管理员不修改作者正文、不代作者发布草稿（草稿行显示"草稿由作者管理"），也不删除他人内容。

**评论治理**：可按内容搜索，按正常、已隐藏筛选；隐藏与恢复只改变公开可见性，不删除数据，恢复后仍需所属攻略公开才会展示。

**目的地管理**：可新增和编辑目的地的名称、类型、国家、省份、城市、介绍、封面、适合季节、上级目的地和展示顺序（数值越小越靠前），并用"停用/启用"切换状态。停用同样是临时状态：从公开列表和新建选择中消失，但不清空攻略、行程里的历史关联，重新启用后恢复可选；修改上级不能选自己或形成循环。

## 9. 常见问题与暂未提供的功能

- **提示登录状态已失效**：重新登录即可；输入框里未提交的评论先复制保存再登录。
- **图片上传失败**：确认是 JPG/PNG/WebP 且不超过 5MB 后重试，已上传成功的图片不受影响。
- **看不到自己的攻略**：多半是"草稿"或"已隐藏"，到 `/me/guides` 切换状态筛选。
- **收藏里的攻略消失**：多半是作者撤回或管理员隐藏，恢复公开后会自动回到收藏列表。
- **攻略被隐藏后想修改**：先请管理员恢复显示，恢复前作者无法自行发布。

当前版本**没有**提供以下功能，请勿按这些预期操作：AI 行程推荐（尚未接入）、地图与路线导航、忘记密码或密码找回、管理员修改用户角色、彻底删除数据的后台操作（内容由作者删除，管理员只能隐藏）。

本站不提供默认账号或统一初始密码；账号由本人注册，管理员账号由平台运营方单独配置并妥善保管。
