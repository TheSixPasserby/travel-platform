# 技术决策

本页记录当前实现的主要取舍，详细契约见 [API](06-api-contract.md) 和 [数据库设计](05-database-design.md)。

| 决策 | 实现依据 |
|---|---|
| Web 与模块化单体 | Vue 处理浏览器交互，Spring Boot 统一维护权限和事务，便于本机演示与部署 |
| MySQL 与关系表 | 用户、作品、互动、地点和行程关联明确，唯一键负责去重 |
| satoken 请求头与字符串 ID | 登录态使用 Sa-Token，JSON ID 避免 JavaScript 整数精度损失 |
| 作者管理内容，管理员治理状态 | 作者负责作品编辑与发布，管理员隐藏或恢复公开内容 |
| 受管原图与独立缩略图 | 原图保留下载与展示质量，列表按受控尺寸降低传输量 |
| Vditor 保存 Markdown | 当前所见即所得编辑和历史源码格式兼容，模式切换检查内容语义 |
| AI 生成预览后确认保存 | 外部结果先校验并供用户编辑，写入阶段重新检查关系和容量 |
| Asia/Shanghai 与固定数据库偏移 | 业务、JDBC 和搜索快照采用一致时间约定，UTC JVM 回归覆盖跨环境差异 |
| 两级评论和显式提及 | 保存根与直接目标，限制显示深度，提及关系需要用户明确选择 |
| 专用每用户评论锁 | 避免互相提及触发用户排他锁与外键锁环，同时串行化频控检查 |
| 固定公共 origin | 分享 canonical、OG 和 sitemap 使用配置地址，避开任意 Host 输入 |
| Web 维护范围 | 历史移动端位于 deprecated，当前构建与验收覆盖 Web 和后端 |

协作运行模型和权限规则集中在 [AGENTS.md](../AGENTS.md)。早期技术设计保存在 [历史索引](history/README.md)，其中阶段测试数量按当时执行结果保留。
