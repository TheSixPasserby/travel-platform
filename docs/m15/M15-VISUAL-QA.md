# M15 · 全站视觉与主题色验收矩阵

## 1. 需要截图的区域

| 区域 | 关键检查 |
|---|---|
| 首页发现瀑布流 | Header、导航、色调、卡片背景、无限滚动、悬停和骨架 |
| 攻略详情 | 标题与正文、右侧操作栏、评论抽屉、作者链接、手机底栏 |
| 创作者主页 | 头像、背景、简介、数字、作品瀑布流、管理入口 |
| 发布与编辑 | Vditor、图文排版、表单、图片上传、保存/发布反馈 |
| 目的地 | 列表/详情/图库/标签/空态 |
| AI 行程 | 结构化输入、预览、错误、保存状态、设置提示 |
| 登录/注册与资料 | 表单尺寸、焦点态、说明/错误、设置一致性 |
| 管理后台 | 顶栏、表格、筛选、编辑器、弹窗、AI 服务设置 |
| M14 图片查看器 | 中性遮罩、工具条主题色、缩放与旋转、关闭和焦点恢复 |

截图至少覆盖 390px 手机与 1440px 桌面、浅色与深色；每个新增预设色需要至少一组核心页面截图，并用代码检查所有页面是否使用语义 Token。

## 2. 主题色专项

- [ ] 六个预设均全站生效，不只是按钮变色
- [ ] 任意合法 `#RRGGBB` 能自定义，输入无效会拒绝
- [ ] 浅色/深色/跟随系统互不影响色调选择
- [ ] 明暗切换后链接、按钮、弱强调面和文本仍清楚
- [ ] 刷新首屏无先绿后变色的闪烁
- [ ] 主题色和明暗各自持久化、跨标签页同步
- [ ] 本地存储禁用时仍然能切换且不崩溃
- [ ] 恢复默认只重置色调，不更改明暗选项
- [ ] 自定义极亮/极暗色仍满足文字可读与焦点区分
- [ ] 颜色不会误伤错误、警告、成功语义
- [ ] 编辑器/抽屉/图库等有独立层叠的组件跟随主题
- [ ] 手机设置浮层能滚动，不被输入法或底部安全区域遮挡

## 3. 回归底线

- [ ] M13 瀑布流无行间空洞、无限滚动、URL 状态与回退恢复
- [ ] 评论抽屉能发布/删除/保留草稿，焦点和背景滚动正常
- [ ] 喜欢/收藏状态通过服务端确认，未登录处理正确
- [ ] M14 图片动画、缩放、旋转、拖动、下载、百分比正常
- [ ] Vditor 三模式与旧 Markdown 数据无损
- [ ] 用户资料、草稿和私有行程不泄露
- [ ] Web-only CI/交付脚本无需 uni-app
- [ ] Reduced Motion 启用时关闭不必要动画

## 4. 开发质量

执行 `npm --prefix frontend test`、`npm --prefix frontend run build`，检查当前项目所用的浏览器验收流程。CI 未完成时不得宣称远程通过。真实浏览器留档截图不能用概念图替代。
