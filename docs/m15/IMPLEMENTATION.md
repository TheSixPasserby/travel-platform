## 设计决定

沿用本地字体栈，衬线用于标题，无衬线用于正文和控件。保留摄影、图文内容、信息结构与卡片瀑布流。空间以 4px 为基础，容器上限 76rem，控件采用至少 44px 点击高度。圆角区分控件、卡片与浮层层级。轻量颜色/阴影/进入退出动效均有统一变量并服从 Reduced Motion。

一个同步头部脚本同时公开色阶运算接口和执行首屏应用，Pinia 复用该接口，避免首屏与挂载后各维护一套算法。脚本在既有 CSS/Vue 入口前加载。保留 `travel-notes.theme`，新增 `travel-notes.accent.v1`。输入仅允许一个合法预设 ID 或严格 `#RRGGBB`，无效存储回退山水绿。

种子色调参与页面、表面和弱强调面。主强调色逐步向黑或白调整，实际 RGB 对所有背景验证对比度。正文 4.5、强调链接 5、按钮文字 4.5、交互边界 3。图片查看器使用独立浅色交互强调色，背景继续中性。危险、警告、成功各自保留语义色。

需重点验证极黑/极白/荧光种子、storage.clear 与无效版本、存储禁用、系统变色不丢色调、Vditor 已打开时主题变化、模态层关闭后焦点与滚动恢复。
