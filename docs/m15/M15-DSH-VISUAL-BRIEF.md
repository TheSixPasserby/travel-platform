# M15 · DSH 前端实际执行任务书

本文件供 Codex 委派 DSH 使用；请同时阅读 `M15-CODEX-IMPLEMENTATION.md`。优先由 DSH **实际编写** Vue/CSS 代码、预设色卡和响应式设置面板，并输出补丁与测试，不是只做 UI 评语。

## 任务 A — 统一组件视觉

在首次页面截图审计的基础上，整理并真正落实统一：

- Header/侧导航/手机底栏、浏览卡片、作者卡片、评论抽屉、阅读页、按钮、输入框、标签及浮层。
- 布局：内容最大宽度、边距、断点、卡片间距、圆角和阴影层级；正文行高、衬线标题层级和图标视觉权重。
- 状态：normal、hover、active、pressed、focus-visible、loading、error、empty 和 disabled。
- 第三方 Vditor 的工具栏、编辑区域及预览样式融入全局主题，不改 Markdown 输出语义。
- 颜色一律从统一的语义 Token 获取；固定深色的图片灯箱应保留中性观图背景，但交互按钮的主题色与焦点色保持统一。

## 任务 B — 个性化主题 UI

在设置弹层新增完整色调选择区：6 个色卡、选中态、合法自定义 HEX、原生调色器、预览、恢复默认。三态明暗与色调分开控制；手机端不溢出。

建议组件：`AppearanceSettings.vue`、`AccentColorPicker.vue`（可按项目情况合并）；优先复用既有 `SiteHeader.vue` 设置区，不创建另一个互不相通的入口。

## 任务 C — 实际交付证据

输出源码改动、截图、主题矩阵结果和响应式对照；提供至少两轮主代理 review 后的视觉修正。不得宣称未运行的浏览器检查已经通过。

## 防回归

不更改用户资料或私有行程权限，不重置 M14 灯箱，不用自定义色覆盖 danger/warning 的语义色；手机浏览器仍在 Vue Web 内，不恢复 uni-app。
