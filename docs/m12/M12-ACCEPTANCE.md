## 测试命令（按项目实际工具确认后运行）

```bash
python3 scripts/backend.py package
npm --prefix frontend ci
npm --prefix frontend test
npm --prefix frontend run build
python3 -m unittest discover -s scripts/tests
python3 scripts/release.py .local/releases/m12-web-only-<unique-id>
```

交付脚本输出位置必须是不存在的新目录，命令中的 `<unique-id>` 需要实际替换。测试库与本地业务库必须严格区分，不要在真实用户数据库中运行破坏性测试。

最终报告逐项标注 **通过 / 失败 / 未执行（原因）**，附截图、CI URL、真实 SHA 和补救措施。
