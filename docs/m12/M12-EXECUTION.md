## 重点失败场景

- 切筛选/路由后迟到响应不能覆盖当前流或作者；错误可重试，空页可回第一页。
- 灯箱关闭/切路由恢复焦点与滚动，缩放不阻塞滑动/键盘。
- 三模式往返不能静默丢旧文；不支持的原文保留源码。图片/粘贴不能引入非受管 URL、Base64 或 HTML。
- 上传/保存期间会话或账号切换不能将旧稿写入新账号；上传上限与失败保持正文。
- 公开资料/相关推荐只返回授权资料与已发布内容，排除当前、删除、草稿/隐藏数据；IP 默认全局禁显。
