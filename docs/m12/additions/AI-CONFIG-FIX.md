# M12 AI 配置联调修复

2026-11-11，针对“配置后仍无法使用”完成实查、修正与真实网页生成验收。

## 原因与修正

1. 保存配置的 enabled=false，密钥已配置。已通过现有管理员 API 启用服务，原密钥逐字节保留。
2. 用户填写的模型为 `deepseek-v4.1-flash`。已核实本机 127.0.0.1:8326 的监听进程为 DSH NE，并从该网关的模型列表确认完整路由 `buddy/deepseek-v4.1-flash`，当前配置已使用该 ID。
3. 第一次真实网页生成触发 30 秒超时，返回 HTTP 504 / 50410。当前配置请求等待已调整为 90 秒。前端整程和单日预览等待统一为 125 秒，覆盖管理员页面允许的 30 秒连接与 90 秒读取范围。
4. 页面此前将 AI 超时显示成通用服务器错误。四个稳定 AI 5xx 业务码现在使用前端固定文案，未知 5xx 沿用通用脱敏消息。
5. 配置页增加当前生效状态。关闭状态下保存会明确提示启用操作，模型字段补充完整 ID 与网关前缀说明。
