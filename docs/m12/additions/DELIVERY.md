## AI 配置行为

- GET/PUT `/api/v1/admin/ai-settings` 要求 ACTIVE 管理员，匿名 401，普通用户 403。
- 保留 OpenAI、DeepSeek、通义千问和自定义兼容服务预设。模型名和 API 根地址可修改，实际调用继续复用现有兼容客户端及行程输出校验。
- 密钥通过密码输入框填写，API 返回 apiKeyConfigured 状态。保存成功清空页面内存中的密钥，账户切换作废旧请求并清空输入。
- 同一接口留空密钥可沿用，更换接口重新填写对应密钥。清除密钥同时关闭 AI。连接、超时、模型及输出长度均有服务端校验。
- 私有文件默认位于 backend 工作目录下 `.local/ai-settings.json`，可通过 AI_SETTINGS_FILE 指向持久化路径。POSIX 文件权限 0600，临时文件与原子替换成功后更新生效快照。
- 多窗口版本冲突返回 409，保存失败保留上次配置。损坏文件会关闭 AI，并在管理员页面显示恢复提示。
- 配置优先级、请求字段与运维方式已同步至 API 契约、用户手册、部署文档和 `.env.example`。
