## 4. 对专项建议的裁定

采纳接口审查对权限、状态、认证、分页、参考数据、禁用、上传和嵌套行程的缺口判断；没有照搬全部建议：

- 保留公开攻略详情的纯公开语义，新增作者私有读取入口，避免公共详情根据登录身份混入草稿。
- 分页非法输入返回 400；不采用静默截断/替换默认值，便于一致验收。
- 热度使用既有点赞关系聚合，不新增浏览量业务或冗余计数。
- 停用目的地详情携带 INACTIVE 状态继续支持历史链接；新建选择与新增关联拒绝该状态。
- dayNo 按旅行日期计算，不用 MAX(day_no)+1，避免创建顺序与旅行日期不一致。
- M1 保持注册登录与资料的最小闭环；目的地和上传留到 M2，未扩大首个里程碑。
