# 项目章程

## 项目名称
旅游攻略分享与行程规划平台

## 背景
游客在旅行前需要查找攻略、了解目的地并组织出行计划。平台通过用户生成内容（UGC）沉淀旅行经验，并提供基础行程规划能力。

## 目标
建设一个基于 Web 的旅游攻略分享与行程规划平台，完成用户注册登录、攻略发布浏览和互动、目的地查询与维护、手动行程创建和每日安排。功能优先级与 `AGENTS.md` 一致：目的地管理为 P0 必须完成，基础后台为 P1 应当完成，AI 推荐为 P2 选做。

## 目标用户
- 游客：浏览公开攻略和目的地；
- 注册用户：发布攻略、互动和规划行程；
- 管理员：维护平台内容和用户状态。

## 成功标准
- 核心业务流程可实际操作；
- 前后端分离架构稳定；
- 数据权限正确；
- 数据库关系和接口契约一致；
- 有可重复部署和演示步骤；
- 有测试记录和毕业设计文档。

## 范围边界
本项目不以在线旅游交易为目标。第一版不实现酒店/机票支付、订单结算、实时导航、实时交通、复杂路线优化和自训练 AI 模型。

## 约束
Vue 3 + TypeScript；Java 21 + Spring Boot 3.x；MySQL 8.x；MyBatis-Plus；Sa-Token；模块化单体；采用双模型协作：Codex 主代理使用 GPT-6.1-Sol / Ultra 负责规划、决策、整合与验收，DSH Subagent 使用 CodeBuddy DeepSeek V4.1 Flash / Max 承担编码、测试、文档整理和专项审查；两类模型不同是有意设计，不是配置错误。
