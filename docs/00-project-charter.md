# 项目概述

山水间是一套旅游攻略分享与私人行程规划平台。用户从公开攻略发现地点，选择文章关联的真实景点，再确认加入自己的行程。社区交流和行程编排围绕这一使用过程展开。

## 用户与职责

| 用户 | 主要操作 |
|---|---|
| 访客 | 浏览公开攻略、目的地、作者主页和搜索结果 |
| 注册用户 | 管理本人作品，点赞收藏、评论提及、读取通知和维护私人行程 |
| 管理员 | 管理账号状态、公开内容、目的地及 AI 服务设置 |

创作者属于注册用户的业务身份，账号角色为 USER 或 ADMIN。私人行程按所有者隔离，管理员的内容治理权限不赋予他人行程访问权。

## 实现范围

平台维护 Vue Web 和 Spring Boot 后端，使用 MySQL 保存关系数据、本地目录保存图片。攻略支持图文编辑、发布与内容治理，行程支持手动编排和可选 AI 预览。酒店机票交易、支付结算和实时导航未纳入当前业务。

核心功能及验收条件见 [需求说明](01-requirements-specification.md)，实际状态见 [项目状态](../PROJECT_STATUS.md)。
