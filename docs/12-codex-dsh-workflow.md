# 开发协作

项目协作规则以根目录 [AGENTS.md](../AGENTS.md) 为准。Codex 主代理负责架构、共享契约、整合与验收，DSH 承担边界明确的实现或审查任务。

## 运行模型

Codex 使用 GPT-6.1-Sol / Ultra，DSH 使用 CodeBuddy DeepSeek V4.1 Flash / Max。分别检查运行时配置，DSH 在派发前通过能力发现和实际探测核实。项目文档中的模型名称不能替代运行配置。

## 任务边界

派发时写明目标、必要背景、允许读取和修改的文件、禁止修改范围、验收条件及交付内容。共享 API、实体、路由和全局样式由主代理统一协调，同一文件的并发写入应避免。

子代理返回实际修改和测试结果。主代理检查差异、接口兼容及完整构建，按执行证据更新项目状态。工具权限围栏需记录并上报，后续接管使用已有授权和可用权限。

## 记录与发布

当前技术说明放在文档主目录，阶段报告保留当时日期、提交、环境与数量。私有配置、数据备份、真实上传和执行日志保存于忽略目录。提交和推送按用户当前授权执行，发布结果记录实际提交及远程流水线。
