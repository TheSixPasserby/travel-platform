## 后端决策

新增 GET `/api/v1/guides/feed` 与 GET `/api/v1/users/by-username/{username}/guides/feed`，返回 records、nextCursor、hasMore，size 默认 12。游标绑定筛选和排序，包含读取时刻、最高 ID 与最后排序键。热门在快照时刻之前的点赞中排序，实时展示计数取实际聚合。历史点赞撤销可能让已读记录再次满足排序键，客户端按 ID 去重并继续游标。

公开游标每次读取重新校验文章公开状态。最初的 30 分钟过期规则经 DSH 后端审查提醒会中断长阅读，Codex 移除，并加入一小时后继续读取的回归。游标继续校验格式、查询指纹、未来时间和 ID 范围。无数据库结构迁移。

CreatorProfile 新增真实 likeCount、favoriteCount，公开返回限定 8 字段。保留旧分页接口，个人私密资源仍使用现有权限规则。
