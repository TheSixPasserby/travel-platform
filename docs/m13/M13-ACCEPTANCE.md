## A. Git / 保全

- [ ] `git status --short`, 当前分支与真实 `origin/main`、最新提交核对；保护未提交改动。
- [ ] 关键表/上传目录备份或 SHA256 指纹检查；没有删 20 篇演示文章、旧草稿、真实评论与上传文件。
- [ ] Vditor、图片灯箱、AI 网页设置、Web-only 构建、IP 禁显、`deprecated/uni-app/` 不回退。
- [ ] 未经用户新授权不 commit、push、merge、部署或 Release。

## B. 瀑布流

- [ ] 360/390/430/768/1024/1440/1920px，浅色/深色，自然比例/图片报错/超长标题/多图、英文用户名不会造成卡片上下大洞或横向溢出。
- [ ] 不能用 `display:grid` 行轨道 + `align-items:start` 伪造 Masonry；实测各列下一个卡片紧接前一个卡片。
- [ ] 首页 `/`、公开攻略 `/guides`、公开作者 `/users/:username` 无页码上一页下一页；管理表格可保留分页。
- [ ] 实测至少两批真实数据连续 append（当前约 20 篇文章，先 12 后余量）；不覆盖前一批，ID 无重复，加载完毕明确结束。
- [ ] 断网/500/慢请求/切筛选/切账号/离开页面/返回页面，加载可恢复，旧响应不污染，滚动与筛选合理保留。
- [ ] 无后台无穷请求；图片加载前占位降低 CLS；分页 API 若仍用于增量加载，确保顺序稳定性。

## C. 详情与评论

- [ ] 桌面竖向按钮组显示真实点赞、收藏、评论、分享、作者；只允许实按钮，不存在假关注或假评论数。
- [ ] 点击评论按钮打开右侧评论抽屉，主体仍可阅读；关闭后正文滚动位置保持。
- [ ] 弹层内部滚动/底部输入固定；评论发布、删除、匿名提示、账号过期、失败重试和计数同步真实运行。
- [ ] Esc、焦点限制与恢复、Tab 顺序、触控关闭、手机软键盘遮挡，满足弹层无障碍标准。
- [ ] 图片灯箱/详情导航/相关推荐/AI 行程入口依旧可用，查看大图不会误打开作者主页。

## D. 用户主页

- [ ] 所有文章卡片作者头像、作者昵称、文章详情头像、评论头像均跳转 `/users/:username`。
- [ ] 每个用户有自己唯一公开主页，直接分享 URL、刷新、浏览其他人可读，不因登录态混用用户数据。
- [ ] 自己点击账号菜单进入自己的完整主页；资料设置位于独立编辑入口，旧 `/me` 正常跳转或兼容。
- [ ] 公开响应只包含昵称、用户名、头像、简介、已发布文章及真实允许公开的统计；私密草稿/行程/收藏/角色/凭据一律不可读。

## E. 全站动效与视觉

- [ ] 页面、卡片、标签、图片、按钮、互动状态、评论抽屉、图片灯箱、加载状态都有统一的恰当动效，未实现处不得标记通过。
- [ ] `prefers-reduced-motion` 已关闭非必需动画，交互仍可用；没有自动粒子、无限重复动画、布局抽动或全页闪动。
- [ ] 性能没有严重回归：实测浏览器无未捕获 JS 错误；布局稳定，首屏图文/交互流畅；能报告 CLS、主要资源和滚动帧状态。
- [ ] 真实浏览器至少产出 8 张与独立参考图对应的验收截图，另外录短片或提供分阶段动效轨迹。
