## 修复与回归

- 真实 HTTP 红灯发现小数被隐式转为整数、锁冲突误报 500、缺少 multipart 字段误报 500；分别补严格数值解析、40902 和 40001 映射。
- 超过 6MiB 请求在 Tomcat 默认吞读上限下断连，定点设置有界 8MiB 吞读，接受上限仍为单文件 5MiB/总请求 6MiB；边界请求现在统一返回 41301。
- Sa-Token 默认防火墙已拦截编码穿越，但默认回调返回 HTTP 200 文本；保留全部安全校验，只将拒绝响应设为 400/40001 JSON。
- 前端真实回归红灯覆盖上传中切换编辑对象、迟到的上级查询覆盖新表单、列表状态切换后表单仍旧值、状态请求未完成就提交旧表单。均先保留失败日志，再定点修复。
- 已挂载的受保护页面收到 401 时，入口会清理会话并导航到登录页；503 保留会话。头像上传只改变预览，保存修改时才 PATCH，失败保持原资料。
