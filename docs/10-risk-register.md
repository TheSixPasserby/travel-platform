# 已知限制与维护事项

| 项目 | 当前处理 | 仍需核查 |
|---|---|---|
| 数据库升级 | 增量文件、隔离副本、结构及原数据指纹比对 | 原业务库的目标、备份及实际迁移回执 |
| 私人资源 | 后端身份与完整父子所有权校验 | 修改接口时保留跨账号回归 |
| 评论并发 | 专用每用户锁、事务、窗口限频及互相提及回归 | 公开运行后的实际并发负载 |
| 搜索时间 | 快照统一 Asia/Shanghai，UTC JVM 回归 | 部署配置与数据库会话时间约定 |
| 内容与上传 | Markdown 清理、纯文本评论、受管路径和解码检查 | 上传目录容量、备份和维护权限 |
| 会话 | Sa-Token 单体内存令牌，实时检查账号状态 | 重启后重新登录的操作说明 |
| 图片 | 原图独立保存，320/640/960 衍生尺寸 | 缓存空间与实际网络表现 |
| AI | 限流、结构校验、预览确认、手动入口 | 真实供应商兼容性、输出质量及使用费用 |
| 公开分享 | 配置固定 origin，过滤公开对象 | 目标域名、代理和超过受控上限后的 sitemap 分页 |
| 浏览器与论文 | 本机 Chromium 与 WPS 检查 | 其他浏览器、提交电脑字体及打印分页 |

测试环境、已执行范围和待验证项目见 [项目状态](../PROJECT_STATUS.md)。
