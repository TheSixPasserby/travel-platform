# M16 / UI 参考图与设计约束

**图片全部是概念设计（不是系统真实截图）。** 其中图像素材是为概念参考生成/复用的示意照片，地名、数值、通知、作者、功能控件可能包含演示信息；实际产品必须绑定真实数据库和经过权限校验的 API。不要直接拷贝图中品牌商标或虚构统计。

## 可读的静态 HTML 原型

`references/prototypes/` 有上述五张对应的静态 HTML / CSS。仅用于帮助理解布局，**无 Vue 状态、请求和真实按钮事件**；不要当成成品产品。可在可访问的本地浏览器用静态文件查看，或以 PNG 为准。`references/assets/` 为概念图使用的图片素材。

## M15 主题一致性

- 不锁死浅色/深色：保持六预设与用户 HEX 自定义，主色从 `M15` 的 CSS Tokens 取，不在生产页面直接写死参考图的深绿/白色。
- 移动版按手机 Web 适配，**不是 uni-app**。桌面有独立侧边栏时，移动端折叠为已有导航结构；不要硬塞固定左栏到 390px。
- 图片使用站内已有受管图片、来源/许可说明，概念图图片不自动成为正式发布素材；正式生产需独立授权核实。
- 视觉强调信息层级、清楚的主操作、不过度重叠、合理 44px 触控尺寸、恰当空白；不要盲目复刻图中标签文案/数值。

## 动效

搜索建议淡入并锚定输入框；行程抽屉以 200–260ms 位移/透明度出现；选中地点给出真实勾选状态；AI 生成进度与失败分离；通知已读成功后轻反馈。尊重减少动态效果，避免图片或瀑布流新增内容布局跳变。
