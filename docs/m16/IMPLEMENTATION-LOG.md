## 阶段 1 契约

- GET /api/v1/search，匿名可读。参数 keyword（最多100码点）、kind（GUIDE/CITY/SCENIC_SPOT/CREATOR/TAG，可省略）、sort（relevance/latest）、size（1–50，默认24）、cursor。
- 返回标准 data 为 {records,nextCursor,hasMore}。记录包含 kind/id/title/subtitle/coverImageUrl/username/href。href 为服务端生成的站内路由。
- relevance 按标题精确、标题包含、关联公开字段匹配依次排序，随后按时间、类型和 ID 稳定排序。latest 只按时间、类型和 ID。游标绑定关键词、类型与排序，逐页重新检查公开状态。
