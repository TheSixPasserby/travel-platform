## 每阶段标准执行结构

**输入**：读取现有源码、明确 API 现状、界定文件 ownership 和可用测试环境。

**编码**：先加失败测试/验收用例，再开发 API+UI，不改变无关模块。

**整合**：主代理复核真实 diff、鉴权、数据库和路由；记录 DSH 实际交付文件及任务 ID，未落地补丁=0 贡献。

**验证**：运行最小相关测试 + 页面交互，之后真实浏览器截图；每个阶段记录通过、失败、未执行，不能使用概念图冒充实际页面。

**退出**：功能可独立演示、数据保存与刷新行为正确、未污染原数据库；否则停在当前阶段并修复。
