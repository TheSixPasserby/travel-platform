# 测试计划与验收标准

## 测试层次

- 后端单元测试：Service 业务规则和校验；
- 后端集成测试：Controller、数据库和认证；
- API 测试：正常、异常和权限；
- 前端组件测试：表单、交互和状态；
- 手工端到端：完整用户流程；
- 安全测试：越权、上传、XSS 和输入校验。

## 安全验收

密码哈希不可逆且不返回；认证上下文决定用户 ID；所有写接口权限检查；资源 ID 不可越权；Markdown 安全处理；上传白名单/大小/随机名/路径隔离；AI Key 不暴露前端；错误不暴露 SQL、堆栈和服务器路径。
