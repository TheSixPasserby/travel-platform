# 开发实施路线图

建议按 8 周估算，实际以学校提交日期为准。每个阶段必须形成可运行增量。

## 阶段 0：基线审查与环境准备
检查需求/架构/ER/DDL/API 一致性；检查 Java、Maven、Node、MySQL；分别核对 Codex 主代理与 DSH Subagent 各自所属模型（两者无需相同）；建立 Git 和工程目录。交付基线审查记录。

## 第 1 周：工程骨架与认证
创建 Spring Boot 和 Vue 3 工程；配置 MySQL、MyBatis-Plus、Sa-Token、BCrypt；统一响应、异常和参数校验；实现注册、登录、退出、当前用户和前端路由。验收：注册登录闭环可用，未登录访问受保护接口失败。

## 第 2 周：目的地与图片
目的地列表、详情、管理员 CRUD；本地图片上传；MIME、大小、随机命名；前端上传组件和初始化数据。验收：管理员可维护目的地，图片安全上传和访问。

## 第 3 周：攻略核心
攻略创建、草稿、发布、编辑、删除；列表和详情；Markdown 安全渲染；图片和标签；作者所有权校验。验收：完整发布和浏览流程可用，越权编辑被拒绝。

## 第 4 周：互动、搜索和个人中心
点赞、收藏、评论；关键词/目的地/标签筛选；服务端分页；我的攻略和收藏。验收：互动幂等，搜索分页正确。

## 第 5 周：手动行程
创建编辑行程；每日安排；项目增删改和排序；日期范围与所有权校验；时间线展示。验收：用户可完成一次完整旅行计划。

## 第 6 周：UI 与响应式
首页、攻略、目的地、个人中心、行程视觉；移动端适配；加载/空/错误状态。验收：主流程视觉一致，无明显布局问题。

## 第 7 周：后台与选做
优先用户、攻略、评论、目的地管理；基础统计。有余力再做 AI 行程推荐和保存。验收：后台权限有效；AI 失败不影响核心功能。

## 第 8 周：回归、部署和毕业材料
单元/集成/API 测试；安全和权限回归；数据库初始化；部署说明；使用手册；论文和答辩材料；演示数据。

## 里程碑原则
P0 优先于 P1，P1 优先于 P2；先完成最小可用版本；阶段测试未通过不堆叠新功能；不以代码行数或页面数作为完成标准。
