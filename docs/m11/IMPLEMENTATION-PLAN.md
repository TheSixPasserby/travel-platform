**Spec:** [M11-WEB-ONLY-IMPLEMENTATION.md](M11-WEB-ONLY-IMPLEMENTATION.md)

## 全局约束

- 不修改业务数据、上传文件、历史 APK/Release、Secrets；不推送/发布/提交。
- 正文仍为 Markdown，100000 Unicode 码点、JPG/PNG/WebP 5MB、最多20图及身份/所有权维持。
- 保留未跟踪的用户原始 ZIP 与规范文档；当前 main@29fa630 为起点，就地实施，避免复制本机数据和凭据。
- 每个行为先失败测试再实现，真实测试与未验证项分别记录。

## 审查重点

- 灯箱路由卸载、焦点/背景滚动、快速切图、非法地址与失败图。
- 复杂 Markdown 或 HTML 不得导入后静默丢失；无修改保存保持原文。
- 上传进行中/失败/插入点、图库记录与正文删除、未保存导航。
- 360/390/430px、桌面、深浅主题、减少动效。
- 归档源码不进入活跃 CI，Web 交付不读取移动端，不包含缓存或密钥。
