# M11 浏览器验收清单

全部业务写入在 `.local/m11/browser` 的新数据库/上传副本完成；原库只读指纹核对。

| 用户行为/状态 | 功能验收 | 视觉证据 |
|---|---|---|
| 攻略正文5图、封面、图库 | 任意索引打开、键盘翻页、Esc/按钮/遮罩关闭、焦点返回/背景锁 | 桌面深色与390px灯箱 |
| 城市/景点封面和图库 | 多图切换，说明/署名/许可链接仍在原页面 | 手机目的地图库 |
| 灯箱异常和离开 | 失败图可关闭、快速切换、触控滑动、切换页面后清理 | 失败提示 |
| 新攻略默认可视化 | 输入正文、标题/粗斜体/列表/引用/链接/分隔线、撤销/重做 | 新建/编辑桌面和手机 |
| 可选源码与旧文 | 3篇旧文和综合夹具语义；切换、保存、刷新、特殊语法完整回退 | 源码警示 |
| 受管图片上传 | 当前选区插入、alt修改、20图/5MB/类型、失败保留正文，上传时阻止发布 | 手机插图 |
| 未保存离开 | 路由/刷新确认，保存不重复，撤回保留未保存内容 | 交互断言 |
| 权限和原业务 | 匿名401、非作者403/404、草稿/作者/发布时间/互动保持 | HTTP及自动化结果 |
| 360/390/430/1440px × 浅/深色 | 页面无水平溢出、工具栏换行、控件可触控；减少动画 | 布局矩阵及截图 |
| 探索性边界 | 恶意HTML粘贴不执行、不载远程图片；不支持的链接/扩展不覆盖原文 | 安全断言 |
