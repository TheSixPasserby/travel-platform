# 集成与 QA 阶段提示词

作为测试负责人，对当前实现进行系统集成和验收。

检查：
1. 前后端 API 契约；
2. schema 与 Entity/Mapper；
3. 注册登录和 Sa-Token；
4. 作者/行程所有权；
5. 点赞收藏唯一约束和幂等；
6. 搜索、筛选、分页；
7. 图片上传安全；
8. Markdown/XSS；
9. 行程日期、排序和权限；
10. 管理员权限；
11. AI 失败降级（若已实现）。

真实执行构建和测试；定位失败根因；不得删除测试或放宽断言制造通过；未执行项明确标记。

可使用 DSH 子代理进行安全审查、契约审查和测试用例审查，其模型须为 CodeBuddy DeepSeek V4.1 Flash / Max（Codex 主代理保持 GPT-6.1-Sol / Ultra，两者无需相同），主代理复核结果。

交付：`docs/test-report.md`、`PROJECT_STATUS.md`、缺陷清单、发布阻塞项和答辩演示风险清单。
